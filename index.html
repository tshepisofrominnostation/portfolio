Case study: prompt engineering, Week 2

The same task, before and after optimisation, from the Clickatell AI Bootcamp.

"Write a professional project description for an AI application. Make it clear and engaging."
"Act as a technical copywriter. Using only the project facts provided, write a 90-120 word portfolio description for a hiring manager. Include: problem, solution, primary technologies, and one concrete user benefit. Use a concise, professional tone. Do not invent metrics or features."

What changed

  • Role, audience, word range, required fields, tone and hallucination constraints are all defined, removing the ambiguity of the baseline.
  • The output becomes repeatable and testable: every run is measured against the same structure, so iteration is faster and scoring is consistent.
